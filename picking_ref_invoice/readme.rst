Nom de ton module (Titre)

Description
-----------
Ce module Odoo permet de afficher la reference du bons de livraison sur la factures 
Il est conçu pour Odoo **16.0**

Fonctionnalités principales
---------------------------
- ✅ Fonctionnalité 1: les references des bons de livraison sur la factures, vue formulaire et pdf

Utilisation
-----------
1. Installe le module via Apps.
2. Profite de [ce que le module apporte].

Facturation
-------------
- Odoo 16.0 (Community & Enterprise)

.. image:: static/description/screenshot.png

Installation
------------
1. Télécharger le module depuis `apps.odoo.com`.
2. Décompresser et placer le dossier dans ton répertoire ``addons``.
3. Redémarrer Odoo et mettre à jour la liste des modules.
4. Installer via le menu Apps.
